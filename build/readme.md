# Operating System
The System() function is used at the start of main(), 
be sure to correct it of you're using anything other than Windows.
Other than that, should work on most operating systems due to the current lack of non-standard libraries,
but read below.

# Compiler
So far I've only used **MSVC v17.10**, as it's justifiably simple for this project.
There shouldn't be many - if any - compatibility issues across compilers I believe, but
check the libraries to be sure. Currently I only use standard libraries,
but I can't guarantee that will continue to remain the case.
